# Мои слова — тренажёр английских слов

Личное веб-приложение (PWA) в стиле Quizlet. Устанавливается на телефон и ПК как обычное приложение, работает офлайн, без регистрации. Слова берутся из вашей Google Таблицы.

## Что умеет

- **Карточки**: тап переворачивает карточку, свайп вправо значит «знаю», влево «ещё учу». Под карточкой можно вручную поставить статус.
- **Заучивание**: раунды по 7 слов, сначала выбор из 4 вариантов, потом письменный ответ.
- **Письмо**: опечатку в 1–2 буквы засчитывает. Варианты через `/` или запятую принимаются по отдельности.
- **Тест**: выбор, «верно/неверно» и письменный ответ. В конце разбор ошибок.
- **Подбор**: игра на время.
- **Повторение**: кнопка «Повторить сейчас» на главном экране.
- Озвучка, тёмная тема, горячие клавиши на ПК, работа без интернета.

## Таблица и статусы

Слова берутся с листа **«Слова для приложения»**: A — English, B — Перевод, C — «Статус фразы». Другие листы задаются в начале скрипта, в `SHEETS`.

| Статус | Когда ставится |
|---|---|
| *(пусто)* | слово ещё не брали в работу |
| **в процессе** | слово попало в партию (по 5 слов), изучение начато. Ошибки при первом изучении статус не меняют |
| **повторить** | слово выучено в партии. Следующие повторения через 1, 3, 7, 14 и 30 дней |
| **не знаю** | ошибка на повторении уже изученного слова |
| **выучил** | верные ответы на **всех** повторениях подряд, включая последнее через 30+ дней |

- Любая ошибка на повторении обнуляет цепочку и ставит «не знаю».
- Выученные слова раз в 2 недели приходят на проверку. При ошибке слово снова получает «повторить».
- Если поменять статус прямо в таблице, приложение примет его: таблица главнее.
- Даты повторений хранятся на скрытом листе `_progress`.

## Подключение таблицы (один раз)

1. В таблице: «Расширения» → «Apps Script». Удалите всё и вставьте код из `apps-script.gs`. В приложении есть кнопка «Скопировать код».
2. Сохраните, затем «Начать развёртывание» → «Новое развёртывание» → «Веб-приложение». «Запуск от имени»: **Я**, «У кого есть доступ»: **Все**. Нажмите «Развернуть» и разрешите доступ.
3. Скопируйте URL `…/exec` и вставьте его в приложение. На телефоне и на ПК вставляется один и тот же URL.

Если позже измените код скрипта: «Начать развёртывание» → «Управление развёртываниями» → карандаш → версия «Новая» → «Развернуть». URL при этом не меняется.

## Как установить (бесплатно, один раз)

Приложению нужен адрес в интернете. Проще всего взять **GitHub Pages**:

1. Зарегистрируйтесь на github.com и создайте репозиторий, например `words`. Тип — **Public**.
2. Загрузите в репозиторий файлы этой папки: `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `apps-script.gs` и папку `icons`.
3. «Settings» → «Pages» → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → «Save».
4. Через 1–2 минуты приложение откроется по адресу `https://ВАШ_ЛОГИН.github.io/words/`.

Установка на устройство:
- **Android (Chrome)**: меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **ПК**: просто откройте ссылку в Chrome и добавьте её в закладки.

Чтобы обновить приложение, загрузите новые файлы в репозиторий. Устройства подхватят их при следующем запуске.

## Горячие клавиши (ПК)

- Карточки: `Пробел` — перевернуть, `→` — знаю, `←` — ещё учу, `Z` — отменить, `S` — озвучить.
- Выбор ответа: `1`–`4`. После ошибки: `Enter` — дальше.
